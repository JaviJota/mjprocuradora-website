# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Marketing site for María José Carralero Medina, procuradora (court representative) in Córdoba, Spain — live at https://www.procuradoraencordoba.es. All user-facing content is in Spanish (`<html lang="es">`); keep new copy in Spanish.

## Commands

```bash
npm run dev       # dev server (astro dev)
npm run build     # production build (Vercel output goes to .vercel/output)
npm run preview   # preview the build
npx astro check   # type-check .astro/.ts files (tsconfig extends astro/tsconfigs/strict)
```

There is no test suite and no linter configured.

## Architecture

- **Astro 5 with `output: 'static'`, `trailingSlash: 'never'` and the `@astrojs/vercel` adapter.** All pages are prerendered; only `src/pages/api/contact.ts` runs on the server (`export const prerender = false`). `/404` is excluded from the sitemap.
- **Single layout:** every page wraps its content in `src/layouts/Layout.astro`, which already renders `<main id="contenido">` (pages must not add their own `<main>`). Props: `title`, `description`, `noindex`. The layout derives `canonical`/`og:url` from the current path and builds `og:image` from the portrait; it also provides the skip link, global `:focus-visible` style and `prefers-reduced-motion` rules. Extra `<head>` content goes through `<... slot="head">` (the home page uses it for its JSON-LD `LegalService` + `Person` schema).
- **Home content:** `src/pages/index.astro` renders `src/components/Home.astro`, which imports the bio text from `src/assets/intro.md` as a component (`<Intro />`), styled with Tailwind `prose prose-invert`.
- **Contact flow:** the form in `src/pages/contacto.astro` is validated and submitted by an inline client `<script>` via `fetch` (FormData) to `POST /api/contact`, and results are announced in a `role="status"` region. The endpoint validates fields and sends two emails through **Resend** (from `info@procuradoraencordoba.es`): one to `OWNER_EMAIL` and a confirmation to the submitter. Form field names include accents (`teléfono`, `descripción`) and must match between the form and the endpoint.
- **Environment variables** (`.env`, also configured in Vercel): `RESEND_APIKEY`, `OWNER_EMAIL`. The endpoint reads them through `dotenv` + `process.env`.
- `nodemailer` is installed but unused; email is sent only via Resend.
- `src/components/recursos.astro` is an unfinished "Recursos" page placed in `components/` (so it is not routed); its Navbar links are commented out.
- Sitemap generated by `@astrojs/sitemap` from `site` in `astro.config.mjs`; `public/robots.txt` points at it.

## Styling conventions

Tailwind 3 (via `@astrojs/tailwind`) + `@tailwindcss/typography`, with `future.hoverOnlyWhenSupported`. Brand colors are theme tokens in `tailwind.config.mjs`: `brand-navy` (#2A3B47, page background), `brand-ink` (#1e2a33), `brand-gold` (#bfa76a), `brand-gold-light`, `brand-gold-dark`. Do not put white text on gold (2.3:1 contrast, fails WCAG AA); gold surfaces use `text-brand-ink`. Use `src/components/Button.astro` (`variant="primary" | "secondary"`, renders `<a>` when given `href`) for buttons and CTAs. Pages follow the same structure: a `max-w-6xl` container, a gold uppercase eyebrow, then a single `h1`. Icons are inline-SVG `.astro` components in `src/icons/` and are marked `aria-hidden`. Images go in `src/assets/` and are rendered with `astro:assets` `<Image>` (decorative images use `alt=""`). Stock photos live in `src/assets/fotos/`, must be free for commercial use (Unsplash License, no visible brands/logos) and are listed in `src/assets/CREDITS.md`. Download them pre-cropped to the aspect ratio they are displayed at (images.unsplash.com `w`/`h`/`fit=crop`) and give `<Image>` matching `widths`/`sizes`; cropping a landscape photo into a portrait box with `object-cover` makes the browser upscale it and it looks blurry on HiDPI screens. The home hero is a full-screen photo banner; `Layout`'s `overlayHeader` prop makes the header float over it. The page background is the `.page-bg` element in `Layout.astro` (CSS gradients + SVG grain, no images).
